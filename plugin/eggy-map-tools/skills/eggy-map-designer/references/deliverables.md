# 地图设计交付物

按任务规模提供最少但完整的组合，不因清单长而省略必要的装配展开，也不把所有文档机械塞给只需要概念讨论的用户。

## 概念与方向选择

- 体验契约；
- 主类型、次类型与结构修饰器选择；
- 路线/循环图和节拍或回合表；
- 主题卡、记忆剪影与首屏承诺；
- 关键假设、参考证据轴和未知项。

## 灰盒与机制验证

- 空间草图、拓扑节点和恢复边；
- 移动/相机标定表；
- 状态、转换、终局与重置表；
- 合作角色/交接/缺员降级契约（如适用）；
- 灰盒验收、试玩矩阵和失败归因。

## 成品化与写入预览

- 视觉系统、场所形态和世界壳体卡；
- 关键镜头账及前中远景合同；
- 装配族局部配方、受控变体和参数化放置；
- 分层展开实例预算、密度账、题材适配账和组件角色绑定账；
- 组件/资源表、逻辑能力映射和精确搭建清单；
- 视区性能账、降级顺序、写入预览和副作用；
- 离线审计结果、人工相机复核、试玩记录和调优规则。
