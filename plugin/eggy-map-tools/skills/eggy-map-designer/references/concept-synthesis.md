# 地图概念合成与创意分化

本文件用于把一句题材、一个玩法标签或一张参考图变成有独立因果的地图概念。目标不是随机拼词，也不是给同一条跑酷线换皮；世界必须改变玩家看到什么、判断什么、经过什么空间，并在流程中发生可见变化。

研究案例只提供结构证据。不能复制其完整路线、谜题答案、角色、商业入口或标志性场景；从案例抽取的原则必须与新的玩家身份、世界过程、拓扑和形状语法重新组合。

## 一张概念卡的六个槽

在类型与坐标前填写：

| 槽 | 要回答的问题 | 不合格写法 |
|---|---|---|
| 玩家身份 | 玩家在这个世界中为何有权做主要动词 | “一个蛋仔” |
| 场所 | 什么具体场域提供空间结构与尺度参照 | “科幻”“好看城市” |
| 世界过程 | 此刻正在发生什么可持续、可升级的变化 | “很危险”“有机关” |
| 主矛盾 | 玩家动作与世界过程为何互相阻碍或利用 | 题材和玩法互不相干 |
| 状态转变 | 开始、中段和结束时，世界分别可见地变成什么 | 只改进度数字或灯色 |
| 记忆剪影 | 玩家离开后能画出的一个轮廓和一个动作瞬间 | 罗列十个道具 |

把六项压成一句因果句：

`作为【身份】，玩家在【场所】中反复【主要动词】，利用/对抗【世界过程】，让【状态转变】，最后留下【记忆剪影】。`

例如“海底”只是一种外观；“作为潮汐档案员，在退潮后短暂露出的拱廊中观察水痕、调闸与回访，让整座档案城从淹没变成可读，最终在重新合拢的水门前看见点亮的主塔”才是可设计概念。

## 从主类型选择会产出空间的世界过程

不要先挑 Prefab。先选一个能持续生成路线、场景状态、交互接口或对局信息的过程：

| 主类型 | 有产出的世界过程 | 它应改变什么 | 常见空壳 |
|---|---|---|---|
| 短竞速 | 分拣、崩塌、风向切换、潮汐窗口、交通调度 | 流线、捷径、落点与风险窗 | 通用浮空板加背景 |
| 章节挑战 | 攀升、修复、深入、逃离、逐层解封 | 章节轮廓、动作课程、检查点和回望 | 同一段障碍拉长十次 |
| 机制解谜 | 路由、校准、配平、重构、观察同一规律的变体 | 输入—连线—结果的空间关系 | 密码牌和随机按钮 |
| 合作 | 供能、交接、牵引、互换视角、同步但不同步行动 | 角色动词、对方机会和会合空间 | 两条平行单人路 |
| 叙事探索 | 复原、迁移、回忆重叠、时间切片、社区重建 | 地标状态、事件后果和回访差异 | 对话串联空房间 |
| 生存 | 收缩、轮换、侵蚀、承重失效、气候周期 | 安全空间、预告、策略位置和终局 | 随机秒杀与永久角落 |
| 积分争夺 | 采集—携带—暴露—提交、热点迁移、区域供给 | 风险收益、归属、退路和反雪球 | 拾到即加分且无限刷 |
| 社交展示 | 节庆点亮、换景巡游、共同布置、观演回流 | 地标网络、活动与返回中心 | 大布景加购买入口 |
| 经营模拟 | 生产、加工、排队、维护、扩建与需求变化 | 可见物流、容量、瓶颈和升级后的空间 | 挂机涨数与菜单购买 |
| 纯音游 | 乐句组装、轨道汇流、舞台逐层响应 | 前读、判定、连击和结果场景 | BGM 加闪灯 |
| Boss 战 | 破甲、夺回场地、利用招式、部位暴露、阶段破坏 | 攻击包络、反制窗、竞技场状态 | 大模型加高血量 |
| 防守 | 路线分期开启、资源运输、阵地轮换、天气改变敌路 | 入口、路径、插槽、核心与波次反制 | 自动打怪观赏图 |
| 潜行 | 巡逻换岗、光照/声场变化、警戒传播、目标后封锁 | 观察位、遮蔽、传感边界与备用撤离 | 黑暗、摄像头和红灯 |
| 回合策略 | 地形翻面、公共事件、资源轮转、行动队列重排 | 合法动作、局面反馈与解析顺序 | 实时乱按后轮流播结果 |
| 体育对局 | 球权转换、场区变化、风/水/重力周期、死球重置 | 跑位、边界、重启与得分机会 | 球形交分道具 |
| 创造沙盒 | 材料获得、模块拼装、测试—返修、作品巡展 | 预览、合法放置、预算、版本与展示快照 | 几个显隐摆设按钮 |
| 阵营推理 | 公共系统失效、任务痕迹、有限报告、会议与角色能力冷却 | 可观察路线、信息不完整性、选票与淘汰后权限 | 换色分队、自由聊天或系统日志直接给答案 |

世界过程必须在至少三个节拍中产生不同但同源的结果：先安全展示，再要求玩家利用，最后与已学条件组合。只能支持一个瞬间特效的词，不足以承担整张地图概念。

## 五种分化操作

从一个普通概念生成三个候选时，每个候选至少改变下列两项，且不能只换标题与颜色：

1. **尺度反转**：日常物变成建筑、角色变成维护者、城市变成棋盘、机器内部变成地貌；同时重做门洞、支撑、表面分缝和镜头参照。
2. **过程反转**：不是逃离崩塌，而是追着崩塌修复；不是躲风，而是引导风打开路线；不是打 Boss，而是诱导它破坏封锁。
3. **拓扑反转**：线性前进改为中心—支线—回流、环线周转、双层交错、竞技场分区或逐步开放网络；终局和恢复随之重写。
4. **关系反转**：竞争资源变为交接对象，合作角色互换能力，观众变成不影响真值的演出参与者，敌人变成可预测的环境工具。
5. **状态反转**：世界从完好到失控、从淹没到露出、从拥挤到空寂、从无电到逐区点亮，且变化同时作用于空间、目标和反馈。

使用反转后重新做类型边界测试。若终局、主要动词或强制时间已经改变，主类型也应改变，不要为了保留最初标签而硬套。

## 三候选法

没有明确创意时，先给三个真正不同的概念卡：

- 候选 A 强调空间过程与可读路线；
- 候选 B 强调玩家关系或系统选择；
- 候选 C 强调世界状态变化与记忆画面。

三个候选不得共享同一个“场所＋世界过程”组合。例如不能同时给“废弃工厂逃生、糖果工厂逃生、玩具工厂逃生”。每个候选只写一张卡、一条 30 秒核心循环、一种主要拓扑和三种装配族；在选择前不展开上千个坐标。

## 七项选择评分

每项 `0/1/2`，总分不是自动决策，但低分项必须修正：

| 项 | 2 分条件 |
|---|---|
| 类型清晰 | 一句话能说出权威终局、主要失败和恢复 |
| 题材因果 | 去掉标题后，世界过程仍改变玩家决策 |
| 变奏容量 | 同一规则能完成展示、验证、变化、组合和高潮 |
| 空间产出 | 能自然产生拓扑、远期地标、近景接口和状态变化 |
| 记忆识别 | 黑白剪影与一个动作瞬间即可区分 |
| 装配产出 | 3–8 个稳定装配族能展开宏观、中层、接触与氛围层 |
| 能力可证 | 关键状态能映射到当前版本证据，未知项有灰盒降级 |

若“题材因果”或“类型清晰”为 0，不进入坐标；若“能力可证”为 0，只能保留概念或改走已声明降级。高总分也不证明好玩，仍需灰盒与目标人数试玩。

## 从概念卡落到基础件

概念确定后，不直接搜索几十种主题资产。依次建立：

1. **主轮廓族**：场所如何包裹路线/对局，例如墙跨、岩壁段、看台扇区、舱段、巨型日常物；
2. **过程族**：世界过程的来源—传递—结果，例如管线、潮痕、风向架、巡逻灯轨、生产输送、棋盘解析轨；
3. **玩家接口族**：落点、操作台、交接台、插槽、目标台、判定线、重启点；
4. **状态变体族**：待机/运行/警戒/破损/修复等少量可替换面，不让所有表皮独立逻辑化；
5. **地标族**：出生、转折、高潮和终局各少量独特剪影。

每族先写局部接口和 A/B/C 变体，再按区域、镜头和层预算展开。数千件来自可信壳体、中层结构、接触细节和受控重复，不来自把概念词拆成数千个无职责装饰。

## 四个原创合成示例

### 竞速：逆风邮港

玩家是云港快递员；浮空邮袋不断改变风向。路线不是普通跑道，而由风标门、帆桥和卸货塔组成。安全段展示顺风，变化段要求选择短逆风线或长顺风线，终点把全部帆面收拢成一只巨大信封剪影。核心规则仍是冲线，风只改变路线效率。

### 解谜：昼夜温室

玩家是夜班园丁；不同植物只在特定光照与水路组合下打开通道。每间温室保持相同的输入台、管线和结果框，变奏依次改变朝向、遮挡与顺序。完成后旧房间从枯萎变为开花，回望既是答案反馈也是方向地标。

### 生存：纸城暴雨

玩家在纸模型城市中躲避逐区渗水。雨不是全场随机伤害，而沿屋檐、排水沟和纸张折线传播；安全空间从街面转到屋顶，再转到逐渐折起的中心广场。宏观纸建筑、折边中层和浸水状态面使用同一薄板语法。

### 回合策略：候鸟车站

双方轮流调度站台与轨道，让候鸟列车完成迁徙路线。每回合选择切道、放行或保留资源，解析时列车按公开顺序移动；季节章节点改变公共地形而不泄露私有计划。记忆剪影是两条轨道在巨型鸟翼钟下重新合流。

这些例子只是展示合成方法，不是待复制方案，也不证明当前组件能实现风场、植物状态、渗水或回合调度。

## 创意验收

1. 不看标题与色板，测试者能否从空间、状态和动作说出世界正在发生什么；
2. 世界过程是否至少产生三个同源节拍，而不是一段演出；
3. 三候选是否至少在两项分化轴上真正不同；
4. 记忆剪影是否能在出生或中期远景看到，并在终局发生可见变化；
5. 主题件隐藏后，基础形状、装配与比例是否仍表达场所；
6. 主类型终局、失败和恢复是否没有被创意词模糊；
7. 当前能力不足时，是否能降级而不伪装系统存在。
