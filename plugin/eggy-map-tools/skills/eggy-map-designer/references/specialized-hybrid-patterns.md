# 专项混合类型模式库

本文件补充纯音游、Boss、防守、潜行、回合、体育、创造沙盒与阵营推理参与混合时的设计边界。先读取 [混合类型地图模式库](hybrid-map-patterns.md)，填写主次、组合方式、唯一终局和状态交接；这里的组合种子不是已审计作品证据，也不证明当前版本具备伤害、寻路、侦测、回合、球权、私密分角或局内建造能力。

只有当次类型保留自己的判断、状态、反馈和失败恢复时，才把它写成 `secondary_type`。若只是题材、一个机关或短暂情绪，改用视觉主题或结构修饰器：最终波出现一个大怪不自动构成 Boss，建造防御槽不自动构成经营，跟音乐闪灯不自动构成纯音游，球形道具也不自动构成体育。

## 先判断组合关系

| 专项主类型 | 常见有效次类型 | 更常是修饰器/主题 | 最危险的伪组合 |
|---|---|---|---|
| `rhythm_performance` | 社交展示、叙事探索 | 随机谱面、非对称分轨 | 音乐跑酷被误写成纯音游；大厅比谱面更强制 |
| `combat_boss` | 合作、叙事探索 | 恐怖、随机招式、累计成长 | 只有大模型与投射物，没有生命、阶段和反制 |
| `defense_strategy` | 经营模拟、合作、叙事探索 | 随机波次、非对称职业 | 经营无限扩张压过守线；建造期和波次同时改库存 |
| `stealth_infiltration` | 合作、叙事探索 | 恐怖、非对称身份 | 黑暗、守卫和监控题材代替可读侦测合同 |
| `turn_based_strategy` | 叙事探索、经营模拟 | 随机、非对称角色 | 演出期间仍能提交动作；经营计时绕过回合权威 |
| `sports_match` | 社交展示、经营模拟 | 载具、非对称位置 | 拾取交分冒充球权；大厅占用没有在开赛前释放 |
| `sandbox_creation` | 社交展示、经营模拟、叙事探索 | 随机目录、累计解锁 | 初始场景吃掉作品预算；展示状态反写作品真值 |
| `social_deduction` | 叙事探索、机制解谜 | 非对称角色、恐怖 | 固定谜底代替玩家推理；叙事事件或共享反馈泄露私密角色 |

同一标签也可能只是主类型内部职责：塔防本来就有资源与建设，Boss 本来就需要多人贡献，体育本来就有团队合作，沙盒本来就有展示。只有新增了可独立描述的次循环，才声明次类型并承担完整专项审计；否则把职责写进主类型合同即可。

## 专项组合共用交接合同

每个组合除通用 `hybrid` 字段外，还要能回答：

1. `secondary_scope`：哪些命名节拍真正属于次类型；不允许写“全程都有一点”；
2. `time_budget`：次类型最多强制占用多少秒、最长连续让主循环停摆多久；
3. `entry_condition`：谁在什么权威状态下打开次循环，重复进入如何去重；
4. `exit_condition`：完成、放弃、失败和缺员分别如何离开；
5. `simultaneous_failure`：主次在同一帧失败时由谁裁决；
6. `cleanup_owner`：谁取消计时器、释放占用、回收对象、撤销临时 UI/镜头并提升代次；
7. `fallback`：能力不可用、缺员、性能不足或次循环超时时，主循环怎样仍能闭合。

把每个交接写成一笔事务：`锁定入口 → 快照必要主状态 → 启动次循环代次 → 提交唯一结果 → 清理次循环 → 恢复/推进主循环`。任何一步可中断时都要指定回滚或向前恢复，不保留“门已开但结果没提交”的半状态。

## 13. 防守主 × 经营次

**何时成立**：防守的波次、漏怪和核心仍决定整局；经营拥有真实的 `输入 → 加工 → 交付 → 容量/升级` 小循环，并改变下一波可做的防御选择。若只是击杀得钱、点槽升级，仍是纯防守。

**组合方式**：默认阶段换挡。建设/生产期可操作资源，倒计时结束后冻结领取、加工提交和扩建；战斗期只消费已经提交的库存或明确允许的应急资源。

**节拍种子**：一笔低风险生产闭环 → 选择把产出投入火力、减速或核心修复 → 新路线预告 → 冻结经营并守波 → 结算损耗和新原料 → 下一轮。终局只由防守控制器提交。

**空间与基础件**：共享堡垒壳体、运输沟槽和状态灯；`WORKSTATION`、缓冲仓和升级架集中在安全后场，`DEFENSE_LANE_BAY`、插槽与漏怪门集中在前场。交接门架同时显示“生产停机/波次启动”，不复制两套货币台和结果舞台。

**必须测试**：加工中切波、满仓切波、并发购买、波中重复领取、漏怪与加工完成同帧、核心失败后仍有员工/传送带运行、第二轮库存代次。性能不足时先降后台员工与可见货物，不删路线预告、插槽状态和核心反馈。

**原创种子**：极夜列车修造站。白天回收零件并选择炮塔弹药、轨道道岔或车头护甲，夜间列车穿过两条受袭线路；未提交的半成品在开战时回到缓冲仓。

[《case-004》](exemplars/case-004.md)为这一有向阶段关系提供部分实证：防守天数/波次保持终局，黄金、食物、人口、科研和职业配置改变后续防线，并有路线分期开启；但没有实际观察建造、切波冻结、连续两波或回到经营阶段，不能把其代码词汇当作完整交接已验证。

## 14. 防守主 × 合作次

**何时成立**：玩家不只是多人一起购买塔；至少两个角色拥有会改变对方防守机会的独占动词，并在波中或波间发生可见交接。

**组合方式**：持续叠层。资源、路线、插槽和核心仍由防守权威管理；合作只改变谁能侦察、供能、建造、操纵或修复。

**节拍种子**：侦察者标记下一路 → 工程者据此切换防御职责 → 波中侦察者开启短反制窗 → 工程者兑现 → 安全期交换岗位。每个角色在目标时间窗内都应有判断和动作，不能一人永久守面板、一人独自玩主循环。

**交接与降级**：交接物必须有一名所有者、一次提交 ID 和越界回收；缺员时提供有冷却的有限代用动作，降低效率但不让核心必败。角色掉线后先释放插槽和交接物，再重分配能力。

**必须测试**：同一插槽并发操作、交接越序、两人同时死亡、角色掉线、第三/第四名玩家的职责、波次结束时交接物仍在飞行、换岗后的旧权限。

**原创种子**：云鲸护航台。一人旋转风向镜揭示隐形航路，一人沿揭示方向布置雷网；每波后两座控制台交换位置，迫使双方理解完整因果。

## 15. Boss 主 × 合作次

**何时成立**：Boss 生命、阶段、伤害提交、团灭和击败拥有唯一权威；合作增加必要但可恢复的角色关系。只有“大家一起打”不需要次类型。

**组合方式**：持续叠层或局部站点。常见关系是 A 暴露弱点、B 提交伤害，下一阶段交换能力；任一角色的动作和对方机会都应由同一阶段状态派生。

**节拍种子**：共同读取招式 → A 引导攻击击破外壳 → B 在短窗内固定核心 → 双方输出 → 阶段转换交换职责 → 组合招式 → 击败提交。不要在不可打断的演出里继续计攻击窗或倒地时间。

**空间与基础件**：以 `BOSS_ARENA_SECTOR` 保持共同移动空间，在相对扇区布置角色接口；弱点框、导流轨和复活口共用竞技场形状语法。合作台不能缩窄躲避净空，也不能形成永久安全角。

**必须测试**：同步伤害、窗口结束同帧命中、阶段阈值跳过、一个角色倒地、全员倒地、缺员、角色换位、第二次挑战残留。降级时缩短或自动补足合作窗口，不伪造另一名玩家的全部体验。

**原创种子**：双核钟楼巨像。一人用反射镜把钟摆冲击引到装甲，另一人攀上短暂暴露的齿轮锁；第二阶段镜面和锁台位置互换。

## 16. Boss 主 × 叙事探索次

**何时成立**：探索所得信息、场景状态或选择改变玩家如何理解/处理 Boss 阶段，但击败、撤退或声明的遭遇结果仍是唯一终局。纯过场和台词不是次循环。

**组合方式**：局部站点或阶段换挡。战前探索给出可观察的招式线索或可选反制，阶段间只进行短而安全的场景揭示；战斗开始后冻结会改变 Boss 权威的旧探索入口。

**节拍种子**：观察遗迹中的攻击痕迹 → 选择一项可见准备 → 进入战斗验证线索 → 阶段破坏暴露新空间 → 短探索取得最终反制 → 回场击败。选择改变路线、工具或场景，不应隐藏必胜信息。

**交接与镜头**：演出入口锁、Boss 攻击时钟、玩家控制、场景变体和目标更新由一个事务提交；跳过与看完得到同一玩法状态。镜头归还后朝向新目标并保留一个安全读图窗。

**必须测试**：跳过演出、演出中死亡/断线、先触发 Boss 再回探索区、阶段转换同帧伤害、重试时旧场景、不同选择是否都可完成。

**原创种子**：沉船心脏。玩家先在三段残骸中发现水压、声呐与阀门线索，选择修复一个系统；Boss 每阶段撕开一层船舱，最终反制与所选系统对应。

## 17. 潜行主 × 合作次

**何时成立**：侦测、怀疑、警戒、搜索、目标提交和撤离仍决定路线；合作让玩家分担观察、诱导、遮蔽、开锁或搬运，而不是两人并排走同一路。

**组合方式**：持续叠层。所有玩家共享可解释的区域警戒，但个体暴露、工具冷却和目标所有权分开；一人的诱导必须让另一人看见传感器朝向、警戒传播或安全窗变化。

**节拍种子**：共同观察巡逻 → A 制造有限诱导 → B 越过并关闭局部传感器 → 安全点交接工具/换位 → 同步目标与撤离 → 警戒状态下使用备用出口。

**空间与基础件**：`INFILTRATION_CELL` 交替提供双视角观察位、绕行口和重新会合区；真实遮蔽代理与视觉墙体一致。角色色只标工具与交接接口，不把整条路线染成答案。

**必须测试**：两人同时被发现、只有一人进入搜索区、诱导者死亡、目标持有者掉线、错序开锁、警戒跨单元传播、缺员和第二次进入。降级可以让玩家轮流控制两种工具，但不能让传感器自动失效。

**原创种子**：月面档案库。一人通过维护窗调整巡逻灯朝向，另一人穿过书库复制数据；每个安全气闸交换终端和移动侧。

## 18. 纯音游主 × 社交展示次

**何时成立**：谱面时钟、判定、连击和结算仍是强制演出终局；社交空间提供组队、选曲、观演、合影与赛后回流。若玩家大部分时间只在大厅，主类型应改为社交展示。

**组合方式**：可选支线。演出中的参与席、观众席和离开口分开；进入谱面前释放大厅交互占用，结束后清理音符代次再回到共享中心。

**节拍种子**：中心选曲/组队 → 倒计时锁定参与者 → 谱面演出 → 结果合影 → 返回中心或下一首。观众只能触发表情、镜头或无判定舞台效果，不能改变分数和音符时钟。

**空间与基础件**：`COUNT_IN_PORTAL` 和 `RESULT_STAGE` 接到 `PHOTO_ACTIVITY_STAGE`；观演区保持来向和判定线可见但不与玩家轨道重叠。大厅灯光可从结果状态派生，不能反向修改结算。

**必须测试**：演出中加入/离开、观众误触、满员选曲、静音、暂停、连续两首、结果页未确认、回大厅后旧连击/灯光残留。

**原创种子**：午夜玩具电台。玩家在环形唱片店组队，进入透明传送轨完成一首机械鼓谱，结算后舞台把队伍连击转成短暂合影灯效。

## 19. 回合策略主 × 叙事探索次

**何时成立**：行动权、合法动作、解析顺序和棋局终局始终是权威；叙事探索在回合外解释棋盘、提供公开选择或改变下一幕场景。若玩家能在探索中绕过对局结果，主次关系已反转。

**组合方式**：阶段换挡。进入叙事段前完成当前解析队列、冻结行动权与倒计时；返回棋盘时以新代次重建局面表现，再明确交给哪一方。

**节拍种子**：读局面 → 提交动作 → 完整解析 → 达到章节点 → 探索一处事件并提交选择 → 重建棋盘规则/外观 → 下一回合。私有信息不能因公共演出镜头或共享文本泄露。

**必须测试**：解析中触发剧情、跳过、行动者断线、双方同时点事件、旧动作晚到、回场后行动权错误、重载章节点、平局进入剧情分支。

**原创种子**：会移动的博物馆棋局。每完成三回合，双方进入同一展厅选择修复一件展品；选择改变下一章公开地形，但不直接赠送隐藏手牌优势。

## 20. 体育主 × 社交展示次

**何时成立**：比赛对象、控球/接触、界外、死球、开球和比分决定比赛；社交提供赛前集合、观战、庆祝和回赛场循环，不参与裁判真值。

**组合方式**：可选支线或清楚的赛前/赛后换挡。开赛锁定场上名单、释放大厅控件并清空练习球；比赛对象只有一个当前代次，观众道具不能进入场地判定。

**节拍种子**：大厅选队 → 热身读场地 → 开球 → 比赛/死球重启 → 结算 → 领奖/合影 → 返回大厅。退出入口不能与球门、边线或重启点共用触发面。

**必须测试**：观众进场、练习球残留、满员换队、开球同帧离队、加时、比赛中房主退出、第二局阵营与比分清理。

**原创种子**：漂浮水球俱乐部。中心码头兼作选队和合影，正式比赛在下层封闭水池；看台玩家只能控制无碰撞助威灯，比赛后升降台把全员送回码头。

## 21. 创造沙盒主 × 社交展示次

**何时成立**：预览、放置合法性、预算、所有权、撤销、保存和退出构成主循环；社交让作品可被参观、合影、投票或共同编辑，但展示状态不能成为作品真值。

**组合方式**：持续叠层加可选展示支线。编辑区、访客区、测试区和展览快照使用不同权限；发布/展示先锁定一个不可变快照，之后的编辑进入新草稿代次。

**节拍种子**：选择目录 → 预览/校验/放置 → 编辑/撤销 → 保存草稿 → 生成展示快照 → 访客活动与反馈 → 返回编辑。投票、点赞或合影只绑定快照 ID，不直接改预算和所有权。

**空间与基础件**：中性 `BUILD_PLOT` 为作品留轮廓与镜头预算，`CATALOG_POD` 集中在边缘，展示区用 `PHOTO_ACTIVITY_STAGE` 但不复制真实作品逻辑。场景壳体和访客 FX 不得吃掉玩家声明的作品峰值。

**必须测试**：多人同时编辑、访客误删、所有者掉线、超预算、重叠预览、保存中测试、旧快照投票、新会话加载、清空作品后展示残留。

**原创种子**：空岛花车工坊。玩家共同搭建花车，锁定巡游快照后访客沿一圈观景路投票和合影；作者仍可在隔离工位继续下一版草稿。

## 22. 创造沙盒主 × 经营次

**何时成立**：玩家仍以创作、修改和保存作品为主要重玩理由；经营提供材料生产、容量和工具升级，服务于创作选择。若大部分时间用于生产和出售，主类型应改为经营模拟，建造只作为其可见升级。

**组合方式**：持续叠层。材料库存和作品预算分别建模；加工完成只增加可用材料或目录权限，放置提交再原子扣除。删除/撤销按声明规则退款，不能通过保存/加载复制材料。

**节拍种子**：完成一次短材料闭环 → 解锁两个不同建造选择 → 预览并放置 → 发现容量/结构瓶颈 → 选择升级生产或编辑工具 → 完成作品里程碑 → 保存/展示。

**必须测试**：加工与放置同帧、撤销退款、满仓、多人领取、所有者掉线、加载后材料与作品不一致、目录解锁回退、展示快照消耗资源、空作品终局。

**原创种子**：废星造船厂。拆解残骸生产结构、动力和装饰三类材料，玩家据此搭建可测试的小飞船；试飞使用快照，坠毁不销毁编辑中的权威作品。

## 23. 阵营推理主 × 叙事探索次

**何时成立**：每局仍由随机/规则分配的隐藏阵营、玩家行为、会议/投票和阵营谓词产生结果；叙事只给场所身份、公共事件与可解释痕迹。若凶手和答案预先固定、玩家只收集线索解锁结局，主类型应改为叙事探索或机制解谜。

**组合方式**：局部站点。叙事事件必须是所有合法玩家可观察或事后可讨论的公共状态，不得借演出镜头、角色台词、专属颜色或系统日志泄露隐藏身份。事件开始前锁入口并声明哪些场上动作继续、冻结或取消。

**节拍种子**：私密分角 → 公共任务与可观察路线 → 一次所有人都能解释的场景事故 → 玩家各自形成不完整观察 → 报告/会议/投票 → 新场景状态改变下一轮路线 → 阵营终局。叙事选择可以改变公共空间或任务顺序，不能直接替某阵营投票或宣判。

**空间与基础件**：用 `DEDUCTION_ROOM_BAY` 构成可辨房间网络，事件地标在多个视角下留下同源但不完整的空间痕迹；`MEETING_HUB` 与故事演出区分开。回访变化应帮助定位与推理，不把玩家导向唯一“正确角色模型”。

**必须测试**：事件中报告、演出跳过、私密角色掉线、淘汰者观看事件、不同镜头是否泄密、会议后场景重建、固定事件是否让某阵营必输、第二局旧台词/角色/选票残留。降级时保留公共场景事件，移除无法保密的角色推断承诺。

**原创种子**：极夜漂流站。每轮风暴会切断一个研究翼并留下公开设备日志，玩家只能从自己所在位置看见其中一部分；会议后修复选择改变下一轮公共路线，但隐藏阵营仍由玩家行为而非预设剧情暴露。

## 不推荐直接混合的情形

- 两个类型都要求持续实时权威，例如纯音游与体育同时决定输入结果；除非其中一个被限制为可选活动，否则应拆成不同子局。
- 两个类型都拥有不可兼容的终局，例如 Boss 击败与生存最后一人各自宣布胜者；应指定一个是阶段验证或破平局规则。
- 次类型强制占用超过大部分目标时长，却仍被称为“点缀”；重新选择主类型。
- 阶段换挡需要保存大量状态，但当前能力不能冻结、恢复或清理；先做单类型闭环，或降级为环境演出。
- 组合依赖未验证 API/组件语义。视觉上可以先做交接壳体，计划仍保持概念/灰盒，不把装饰当作系统证据。

## 专项混合验收

1. 移除次循环后，主终局仍可描述；移除主循环后，整局重玩理由或权威终局消失；
2. `secondary_scope` 能逐项对应命名节拍，且强制占用与最长停摆不超过声明预算；
3. 主次同时完成、同时失败、重复进入、中断、缺员、掉线和第二局都有唯一裁决；
4. 入口锁、状态快照、结果提交、清理和主循环恢复属于同一代次；
5. 静态装配、状态件和逻辑/生成物分别预算，交接区不会把两个类型的峰值全部叠在同一镜头；
6. 能力不足时按已声明降级回到闭合主循环，而不是用文本、模型或灯光假装次类型成立。
