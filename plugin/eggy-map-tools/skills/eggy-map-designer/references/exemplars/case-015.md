# 匿名案例 case-015

原始名称与身份字段已移除；下文只保留聚合观察、设计推断和证据边界。

## 为什么读它

这是一张角色能力型合作图。它适合回答：怎样让“合作”成为双方动作之间可见、可恢复的因果链，而不是两条并行路线、装饰按钮或只在终点会合。

## 证据范围

- 有单人出生区观察与发布缓存聚合数据，没有完成双人试玩。
- 发布缓存包含 3,408 个批加载渲染单位、100 种模型路径和较高逻辑复杂度；运行时单位与触发计数不能换算为编辑器顶层组件或“每件脚本量”。

## 构成拆解

- **角色契约**：小蚯蚓能刨土，蛋仔能利用刨出的路线；小蚯蚓还能把蛋仔翘到新的落点。每个角色有独占动词。
- **空间交付物**：帮助的结果不是抽象加分，而是对方可直接看见和使用的新路径、落点或通行机会。
- **往返交接**：一个角色改变世界后，另一角色继续推进并创造下一次回馈机会，避免长期由一人操作、一人等待。
- **缺员分支**：字符串表存在单人关卡、单双技能、存档和分路线索；单人兼容是显式状态分支，而不是偶然绕过合作门。
- **世界表达**：出生区先用热带泥地、树木和木台建立场所，再介绍伙伴与能力。约一半渲染单位来自同一可变形方块，配合棱柱、圆柱和少量不可见碰撞塑造场景与角色轮廓。

## 可迁移设计卡

每次合作交接写成：

`A 的独占动作 → 世界中可见的变化 → B 获得新机会 → B 的必要动作 → A 的回馈路径/双方会合`

并逐项回答：

| 字段 | 应明确的内容 |
|---|---|
| 角色权限 | 每名玩家有什么别人不能替代的动词 |
| 因果反馈 | 对方能否看到谁做了什么、哪里发生变化 |
| 等待上限 | 非操作方最长多久没有移动、判断或准备任务 |
| 交接失败 | 对象丢失、两人同时死亡、顺序错误时怎样恢复 |
| 检查点 | 保存哪些共同进度，重生后如何重新绑定角色/能力 |
| 缺员模式 | 单人、掉线或多出玩家时走哪条明确状态分支 |

同一种因果语法可以重复，但空间动作应变化：抬升、开路、承重、转向、搬运或远程触发分别形成不同交接，不用同一按钮镜像八次。

## 不应照搬与未知

- 不复制角色设定、故事、任务顺序、谜题答案或具体触发命名。
- 现有证据不能证明双人等待、公平、掉队恢复、完整交接次数或单人分支实际无软锁。
- 角色提示文字只能用于首次解释；正式设计仍要让动作、路径变化和同源反馈表达因果。

## 身份

- `[元数据事实]` 标记为双人策略图，并明确注明“可单人游玩”；有效游玩约 236.8 万、点赞 471,071、评分聚合约 4.66。

## 证据

- `[视觉观察]` 出生区先用热带泥地、树木和木质落脚台建立场所，再用短对话提示“雨后湿润泥土里藏有东西”；提示结束后可见伙伴角色、蚯蚓交互台和明确的前进地标。
- `[代码事实]` 归档为 51 块、8 字节表项布局；批加载渲染单位 3,408，模型路径 100 种，ECA 触发计数 9,652。
- `[代码事实]` 可变形方块/箱体模型出现 1,725 次，占批加载单位约 51%；非均匀缩放 2,971 个，说明大量场景和角色轮廓由少量基础几何塑形。另有三棱柱 364、圆柱 170、不可见碰撞盒 94。
- `[代码事实]` 字符串表包含 15 个存档区域、15 个开关区域、8 个“分路”前缀，以及单人存档、单人关卡、单双技能和销毁单人双技能等兼容状态线索。
- `[代码事实]` 角色提示明确写出“小蚯蚓可以刨土，蛋仔可以走小蚯蚓刨过的路线”和“小蚯蚓负责把蛋仔翘过去，然后走泥土路过去”，证明角色动作会产出另一角色可利用的路径机会。
- `[代码事实]` 多个章节门、提示、任务、资源收集、场景状态和恢复命名共同说明其系统层不是一条并排双路线。

## 蒸馏

- `[设计推断]` 真合作的基本单位不是按钮，而是“角色独占动词 → 可见世界变化 → 对方获得新机会 → 下一次交接”。刨土和翘起都是对方能直接利用的空间产物。
- `[设计推断]` 高质量合作图需要角色契约、交接契约和缺员降级契约同时存在。单人兼容不是关闭双人门，而是给单人能力、存档和章节状态建立独立分支。
- `[设计推断]` 角色差异应通过可操作对象与动画结果表达，文字只承担初次说明；出生区先让玩家认识伙伴与主题，再进入强依赖环节。
- `[设计推断]` 大量系统逻辑可以建立丰富合作章节，但必须用存档和分路把失败损失切小，并在测试中分别验证双人、单人、掉队和重生状态。
- `[设计推断]` 美术仍遵循窄资产词汇：约一半单位来自同一可变形方块，少量植被、围栏、云与角色部件负责主题识别。

- 不复制角色设定、故事、任务顺序、谜题答案或具体触发命名；可迁移的是角色权限、空间交付物、章节交接和单人降级的结构。
- 本轮只观察了单人出生区，没有双人完整试玩；字符串能证明能力与状态存在，但不能还原触发图、实际交接次数或角色公平性。
- 需要后续用另一张共享搬运或同步窗口型合作图做反例，验证该结构是否适用于非叙事合作。
