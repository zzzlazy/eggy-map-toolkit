# 匿名案例 case-005

原始名称与身份字段已移除；下文只保留聚合观察、设计推断和证据边界。

## 审计范围

- 游戏版本：1.0.291，MuMu macOS Profile。
- 证据：用户提供的出生区截图、公共地图 `本地原始证据（未分发）` 缓存、地图 detail metadata、file ID 95 的批加载数据，以及当前版本组件目录。
- 原始地图归档未纳入技能；以下只保存聚合指标和设计结论。

## 地图定位

简介明确写有 240 关峡谷跑酷，并包含普通/困难模式。缓存元数据记录：

- 游玩数 `4,323,871`，胜者数 `223,767`，约占 5.2%；
- `pass_time_mid=623.9s`，约 10 分 24 秒；平均通关时间明显更长，分布高度偏斜；
- `total_op_num=60,351`、`total_edit_map_num=233`、`map_cost_time=401,239s`；
- `eca_trigger_count=1,716`；
- 启用存档，并提供简单/困难成就与对应排行榜；
- 配置垫脚石、时间胶囊、无冷却滚动和瞬移等容错/加速资源。

这些数字说明它是长期迭代的超长挑战图，不应作为两分钟短图的直接数量模板。

## 代码结构事实

发布归档包含 49 个数据块；主要压缩块包括约 452 KB 的 `unit`、32 KB 的全局触发数据和 40 KB 的触发编辑数据。批加载数据中有：

- 6,455 个批加载单位，95 条非空模型路径；
- 53 组动态网格路径、143 组批量合并模型映射；
- 6,265 个明确可见单位、47 个明确隐藏单位、143 个未携带可见性字段的合并记录；
- 3,719 个启用物理、1,486 个关闭物理、1,250 个未携带该字段；
- 4,915 个接收阴影但关闭投射阴影，1,382 个同时接收和投射；
- 6,296 个带缩放数据的单位中，5,805 个使用非均匀缩放，3,491 个至少一轴缩放不小于 5；
- 6,312 个带旋转数据的单位中，2,947 个在 X 或 Z 轴有明显倾斜。

高频模型显示出明确的模块化形状语法：

- 方块-可变形 2,298；基础圆柱 405；圆锥-可变形 315；四棱锥 131；圆环-可变形 97；1/4 方圆环 95；
- 草 210、天然草地 1/2 共 132、三类草地岩石共 186；
- 深水渲染模型 135；
- 道具箱 63、蹦床 62、传送带 32、悬浮文字 28。

`box2` 模型另有 685 个，但该模型被多种触发/区域复用，不能仅凭模型路径断言具体 EID。

## 色彩与材质

第一染色区的前三种颜色约占所有已记录颜色的 63%：

- 中性岩灰 `(137,145,149)`：1,708；
- 暖木棕 `(180,146,93)`：1,519；
- 高饱和引导绿 `(31,231,35)`：757。

岩灰主要用于方块、圆柱、岩石和拱环，并大量搭配石质材料；暖棕主要用于基础几何、破旧木条和木梯；绿色主要落在通用方盒与动态形状上。另有 85 个发光亮绿圆锥，强化方向提示。截图中可见灰色峡谷/台阶、绿色连续落点提示和暖色木制信息板，与代码统计一致。

## 画面观察

- 出生点位于宽阔安全平台，允许先观察再进入关卡。
- 近景台阶把视线引向左侧；峡谷壁在两侧形成包裹和纵深，不是空底板上的悬浮障碍。
- 远处高亮洞口和体积光形成长期目标；绿色落点形成短期目标。
- 前景角色、中景路线、背景洞口三层关系清楚。灰雾压低背景对比，让白色逆光与绿色路线突出。
- “简单”难度标签与丰富场景同时存在，说明低操作门槛不等于低视觉完成度。

## 可迁移原则

1. **先塑环境，再嵌路线**：大量基础几何承担峡谷、台阶、拱洞和支撑，主题不是靠少量成品岩石撑起来。
2. **少模型、多变换**：95 种模型支撑 6,000 余批加载单位，非均匀缩放和倾斜是主要造型手段。
3. **色彩承担信息**：灰色统一环境，棕色表达木构，绿色持续表达可前进方向；强调色不是平均撒点。
4. **目标分层**：玩家同时拥有下一落点、当前章节出口和远期峡谷顶三个尺度的目标。
5. **玩法与长期系统匹配**：240 关带来存档、难度模式、成就、排行和容错资源；这些系统来自地图尺度，而非通用必选项。
6. **优化是设计的一部分**：大量单位关闭投影或物理，并存在动态网格与合并映射；高密度场景不能默认全碰撞、全阴影。
7. **高完成度来自迭代**：元数据记录的大量编辑操作与多次编辑说明，优秀地图需要骨架、场景、测试和优化多轮收敛。

## 不应照搬

- 240 关、十分钟以上中位时长、低总体胜者比例不适合轻量两分钟地图。
- 商店、广告、排行榜和复杂存档只在长期玩法中成立。
- 6,455 个批加载单位是发布运行时口径，不等同于推荐单位预算，也不等同于编辑器顶层组件数。
- 截图只证明出生区构图，后续章节的节奏仍需更多画面或试玩记录验证。
