# 空间拓扑与整局循环

## 先选拓扑

拓扑描述玩家、目标和资源如何连接，不等同于建筑外形。按主循环选择一种主拓扑，必要时局部混合：

| 拓扑 | 适合 | 必须解决 |
|---|---|---|
| 线性链 | 短竞速、章节挑战、叙事推进 | 下一目标、复位距离、节拍变化 |
| 分支再会合 | 竞速、合作、风险捷径 | 路线价值、会合拥堵、信息公平 |
| 环路/赛道 | 圈速、追逐、循环收集 | 朝向识别、套圈/逆行、重复景观辨识 |
| 中心辐射 | 探索、任务、社交、阶段挑战 | 中心可读、支线完成反馈、回程成本 |
| 竞技场/场域 | 生存、争夺、对抗 | 出生公平、视线、热点、退路、边缘滥用 |
| 网络/开放区 | 探索、收集、沙盒、阵营推理 | 地标层级、循环动线、迷路恢复、内容空洞、观察痕迹与信息泄露 |
| 垂直叠层 | 攀爬、生存、立体争夺 | 上下层对应、掉落去向、镜头遮挡、捷径控制 |

地图轮廓可以很复杂，但玩家决策图应能画清。若无法解释从任意重要节点如何到达目标、恢复区或下一次有效决策，拓扑尚未完成。

## 空间关系表

对出生、目标、资源、冲突点、安全点和恢复点记录：

- 彼此的实际行进时间，而不只比较直线距离；
- 到达前能获得的信息与可见地标；
- 至少一种进入和离开方式，或明确说明为何是单向；
- 目标人数同时占用时的拥堵与镜头；
- 掉落、击退、传送或重生后回到循环的位置。

对称外形不自动产生公平。坡度、转向、镜头、出生朝向、掩体和移动机关会改变真实行进时间。

## 整局状态机

所有可重复玩法至少定义：

1. **准备**：玩家出生、规则可见、关键对象归位；
2. **开始**：统一释放控制权和计时，避免有人提前占位；
3. **进行**：主循环、得分/推进、失败与重生；
4. **阶段变化**：危险升级、目标迁移、地图收敛或角色换位；
5. **终局**：胜、负、平局和无人完成的判定；
6. **结算与重置**：停止旧机关，清理分数、状态、生成物和一次性触发，再进入下一局。

把每条状态转换写成 `来源状态 + 条件 → 目标状态 + 反馈 + 清理动作`。同一条件重复到达时不得重复发奖、重复生成或越过必要阶段。

检查点、对象、合作交接、计分、叙事演出、经营事务和随机选择的具体状态合同与异常矩阵见 [触发、状态机与重置模式](logic-and-reset-patterns.md)。

## 任务对象与章节状态

护送、收集、伙伴和搬运图还要把世界对象纳入状态机。对每个必要对象记录：归属、当前位置、是否已计入进度、离开合法区域的回收点、玩家重生时的处理和章节切换时的清理。

每章使用 `所需对象/人数 + 玩家动作 + 完成区域 → 可见变化 + 下一章开放 + 检查点提交`。完成条件尽量让玩家在场景里直接看见，例如伙伴归队、容器填满、门体打开或地标点亮；UI 数字只作确认。完成事件必须幂等，避免对象多次进区导致重复计数。

## 社交空间会话循环

社交图可以没有传统胜负，但仍要设计可恢复的会话状态：

1. **到达与定向**：出生处看见中心地标、一个近处活动和一个远处诱饵；
2. **选择与活动**：玩家能在观察、合影、轻玩法或表达控件间做选择；
3. **换景或回流**：每个活动点至少有清楚的离开方式，传送后能识别当前位置；
4. **重新汇合**：多人走散后能低成本回到共同锚点；
5. **离开与清理**：临时外观、文字、召唤物和占用状态不会污染下一次进入。

对社交地图不要用“没人通关”判断失效；更重要的是首次有效行动、活动点停留、回流时间、多人并发和空闲质量。

## 阵营推理的信息拓扑

阵营推理不仅画可走边，还要画谁能在什么位置知道什么。为每个房间、门槛、任务/事件、报告入口和会议位记录：

- 公共事实：所有人可见且允许讨论的世界状态；
- 局部观察：只有身处视线/声场或完成合法动作的玩家能获得的信息；
- 私密状态：角色、阵营、个人冷却或手牌，只能发给合法所有者；
- 可伪装行为：不同角色都能做、但成本或时序可能不同的公开动作；
- 禁止泄露：出生位置、专属颜色、共享特效、名字标记、观战镜头和系统日志不能间接给出真相。

场上网络应同时有可辨房间、至少两条合理绕行和若干能形成时间/路线推理的门槛；完全同质的迷宫只会制造记忆负担，单一瓶颈则让位置推理退化为堵门。会议是状态换挡，不是普通传送：先冻结场上输入和占用，再集合、讨论、投票、解析，最后恢复一个新场上代次或进入终局。

## 回合节奏

线性图用沿路线的节拍，回合图用时间和局势节拍：

- 前期让玩家建立位置、资源与规则认知；
- 中期制造可读的接触、换位或目标迁移；
- 后期主动收敛空间、资源或胜利条件；
- 终局迅速给出结果并停止仍能改变胜负的对象。

随机性只改变可预测范围内的局势，不隐藏失败原因。危险、资源或目标随机出现时，给所有受影响玩家足够的预警和可行反应。

## 公平与反雪球

- 比较各出生点到首个有价值目标的行进时间、风险与视线；只量世界坐标不够。
- 强位置应付出暴露、绕行、驻守或资源消耗，并存在至少一种可读反制。
- 领先者不应同时垄断更快移动、更强道具、最佳视野和下一轮资源刷新。
- 追赶机制提供机会而非保证翻盘；其条件和效果需要让领先与落后双方都能理解。

## 非目标行为

专门检查玩家可能做但不推进设计目标的行为：出生蹲守、永久躲藏、逆行、绕过触发、把必要道具带出区域、堵住唯一入口、停在相机死角。先通过空间和规则消除收益，再考虑添加禁区或强制传送。
